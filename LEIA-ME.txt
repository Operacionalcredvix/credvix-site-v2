CREDVIX V2 - BLOQUEIO TEMPORARIO DO ACOMPANHAMENTO

Este patch NAO substitui arquivos completos: o instalador faz alteracoes pontuais em:
- src/app/App.tsx
- src/components/integridade/IntegridadeCtaBanner.tsx

Efeito:
- /canal-de-integridade/acompanhar redireciona para /canal-de-integridade
- CTA "Acompanhar relato" fica visivel, mas como botao desabilitado sem navegacao
- Home, Lojas, Vagas, Header, Footer, formularios e Secao de Transparencia preservados
- Nao modifica endpoints Supabase nem desativa o canal legado, apenas o frontend V2.

APLICACAO
1. Extraia o ZIP NA RAIZ de credvix-site-v2.
2. No terminal do VS Code, dentro desta pasta, execute:
   node aplicar-bloqueio-acompanhamento.mjs
3. Rode: npm run dev
4. Confira que o botao do banner nao navega e que a rota direta redireciona.

A execucao repetida e segura (idempotente).
Para desfazer futuramente, restaure os dois arquivos usando Git ou outro patch.
